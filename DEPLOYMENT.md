# Deployment

Connected to Cloudflare Pages project `sixthvision-caravan-studio`.

Auto production deployment: every push to `main`.

Build: `node scripts/build.mjs`, publish `dist`.

This is a **development preview** using illustrative caravan images. The original edited Dropbox photographs and finished video files are not in this repository. The enquiry system creates a local brief and does not deliver submissions. Intentionally noindex until media and functional contact approval.

Live QA should be performed on the actual `https://sixthvision-caravan-studio.pages.dev` URL after Cloudflare reports a successful deployment.
